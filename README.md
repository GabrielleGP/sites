# Sites

Early websites I built with HTML, CSS and JavaScript:

- **Site:** a two-page static website (home page and an "Aventura" page) with custom CSS
- **Responsive site:** a TV-series showcase page with a layout that adapts to phone, tablet and desktop screens
- **Detector site:** a multi-section landing page built with Bootstrap, jQuery and plugins such as AOS scroll animations and Owl Carousel

Each site is stored as a `.rar` archive. Download and extract one, then open its `.html` file in a browser.
